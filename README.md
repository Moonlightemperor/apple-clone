# 📱 Apple iPhone 15 Pro Website Clone

A modern Apple iPhone 15 Pro inspired website clone built using React.js, GSAP, and Three.js.

The project focuses on creating smooth animations, immersive 3D experiences, responsive layouts, and high-performance frontend interactions inspired by Apple’s product landing pages.

---

## 🚀 Live Demo

🔗 Live Website: https://new-15.netlify.app/

---

## ✨ Features

### 🎬 Smooth Animations
- GSAP-powered transitions and scroll animations
- Smooth section-based animations
- Interactive UI effects

### 🧊 3D Model Integration
- Integrated 3D iPhone models using Three.js
- Interactive model rendering
- Dynamic visual presentation

### 📱 Responsive Design
- Fully responsive across devices
- Mobile-first optimized layout
- Adaptive UI components

### ⚡ Performance Optimization
- Lazy loading optimization
- Optimized rendering for smoother experience
- Improved frontend performance and responsiveness

### 🛠️ Monitoring & Debugging
- Integrated Sentry for error monitoring and debugging
- Performance tracking setup
